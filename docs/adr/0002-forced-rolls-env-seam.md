# Forced rolls through an environment variable, the third test seam

The mod's rolls can be forced with the `SQUISHYS_FORCE_ROLL` environment variable (`plain`, `shiny`, `legendary` or `shiny-legendary`), a production setting that the tests use as a third seam beside the mod test kit and the pure modules' seeded tests. The mod's randomness can't be seeded from a test, since each plugin runs in an environment of its own. Without forcing, a random shiny (about one roll in 113) would sparkle, toast and chime in tests about something else and fail them at random. So the tests force plain rolls by default and shiny or legendary ones to see a Moment, and a person trying the mod out can do the same. A roll forced to come up shiny or legendary is never recorded in the Squishydex, so forcing can't fill it.

# Focus view in the pane instead of swapping the main view

Picking a squishy opens its agent in the pane's focus view, and the orchestrator stays in Claude Code's main view. We wanted the chosen agent to swap into the main view, but Claude Code lets a mod only read which transcript is on screen, never switch it; only the user can, through Claude Code's own agent panel or `/tasks`. The pane follows the user instead, highlighting the squishy of whichever agent they open in the main view.
